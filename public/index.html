💸 Transfers HMAC-SHA256
POST
/transfers X-IP-Signature
Recebe uma transferência de outra IP. Roda pipeline: KYC → Blocklist → Limites → AML → Liquidação → Webhook.
GET
/transfers/{transfer_id} X-IP-Signature
Consulta status de uma transferência pelo ID.
POST /transfers — Body
{
  "idempotency_key": "uuid-gerado-pelo-remetente",
  "amount":          1500.00,
  "currency":        "BRL",
  "transfer_type":   "PIX",
  "description":     "Pagamento fatura #1234",
  "sender": {
    "document":   "12345678901",  // CPF sem pontuação
    "name":       "João da Silva",
    "ispb":       "00000000",      // ISPB 8 dígitos
    "account":    "12345-6",
    "account_type": "CHECKING"
  },
  "receiver": {
    "document":   "98765432100",
    "name":       "Maria Souza",
    "ispb":       "12345678",
    "account":    "98765-4",
    "account_type": "SAVINGS"
  }
}
Resposta 201
{
  "transfer_id":     "txn_uuid",
  "idempotency_key": "uuid-do-remetente",
  "status":          "PROCESSING",
  "amount":          1500.00,
  "currency":        "BRL",
  "created_at":      "2025-01-15T10:30:00Z"
}

// Status possíveis:
// PENDING · PROCESSING · SETTLED · FAILED · REVERSED

// Headers obrigatórios no request:
// X-IP-Signature: {key_id}.{timestamp}.{hmac_hex}
// X-Idempotency-Key: uuid
🔔 Webhooks
POST
/webhooks X-IP-Signature
Recebe callbacks de status: TRANSFER_SETTLED, TRANSFER_FAILED, TRANSFER_REVERSED, TRANSFER_RECEIVED.
Payload do Webhook
{
  "event":       "TRANSFER_SETTLED",  // ou TRANSFER_FAILED / TRANSFER_REVERSED
  "transfer_id": "txn_uuid",
  "timestamp":   "2025-01-15T10:30:05Z",
  "data": {
    "transfer_id":     "txn_uuid",
    "status":          "SETTLED",
    "amount":          1500.00,
    "settled_at":      "2025-01-15T10:30:05Z",
    "failure_reason":  null
  }
}

⚙️ Admin — Blocklist · Limites · Audit X-Admin-Key
POST
/admin/blocklist X-Admin-Key
Adiciona CPF, CNPJ, ISPB ou conta à blocklist.
DELETE
/admin/blocklist/{id} X-Admin-Key
Remove entrada da blocklist.
POST
/admin/limits X-Admin-Key
Define limite por escopo: global, peer_ispb ou account.
GET
/admin/audit X-Admin-Key
Consulta audit trail com filtro por evento e transfer_id.
GET
/admin/audit/verify X-Admin-Key
Verifica integridade da hash chain completa do audit trail.

📄 Partner Onboarding API
POST
/partner/submit PUBLIC
Parceiro submete dados da instituição via formulário multipart.
POST
/partner/{ref}/documents PUBLIC
Upload de documento (multipart/form-data). Um arquivo por request. Gera SHA-256 automático.
GET
/partner/submissions X-Admin-Key
Lista todas as submissões de parceiros. Filtro: ?status_filter=PENDING|UNDER_REVIEW|APPROVED|REJECTED
PATCH
/partner/submissions/{ref}/review X-Admin-Key
Aprova, rejeita ou marca como UNDER_REVIEW. Aceita comentário.
PATCH
/partner/documents/{id}/verify X-Admin-Key
Marca documento como verificado após conferência manual.
GET
/partner/documents/{id}/download X-Admin-Key
Download do arquivo original enviado pelo parceiro.
🔐 Autenticação HMAC-SHA256
Como assinar um request
# Header obrigatório:
X-IP-Signature: {key_id}.{timestamp_ms}.{hmac}

# Onde hmac = HMAC-SHA256 de:
"{method}\n{path}\n{timestamp_ms}\n{body_sha256}"

# Exemplo Python:
import hmac, hashlib, time, json

body    = json.dumps(payload).encode()
ts      = str(int(time.time() * 1000))
msg     = f"POST\n/transfers\n{ts}\n" \
          + hashlib.sha256(body).hexdigest()
sig     = hmac.new(secret.encode(),
          msg.encode(), hashlib.sha256).hexdigest()
header  = f"{key_id}.{ts}.{sig}"
Variáveis de ambiente (.env)
# Identidade desta IP
THIS_ISPB=00000000
